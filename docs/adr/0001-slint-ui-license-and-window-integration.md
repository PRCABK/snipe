# ADR 0001: Slint UI 框架选型与原生窗口集成策略

## 状态
已采纳 (Accepted)

## 上下文
Snipe 需要在 Windows 平台上提供低内存、快速启动且视觉现代的截图与标注体验。传统 Electron 占用过大（>150MB 空闲内存），C++ Qt 依赖繁重且构建链复杂。

## 决策
1. 选用 **Slint 1.9** 作为声明式 GUI 框架。
2. 窗口样式采用纯 Slint DSL 定义，复杂系统集成（系统托盘、全局快捷键、命名管道 IPC、Credential Manager）通过平台层 Win32 抽象进行。
3. 遵循开源许可协议，保持代码模块解耦。

## 后果
- 优势：编译体积小、空闲内存可控制在 50MB 以内、声明式界面易维护。
- 权衡：特定底层 Win32 特殊消息需通过平台消息窗口进行中转分发。
